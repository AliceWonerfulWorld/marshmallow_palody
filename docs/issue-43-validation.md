# Issue #43: 投稿前の公開範囲説明

対象: UX-002 / [#43](https://github.com/AliceWonerfulWorld/marshmallow_palody/issues/43)。

## 表示と送信時の方針

個人・共有の公開ページから、取得した公開モードと箱の種類を投稿フォームへ渡す。公開は未回答も送信直後から誰でも閲覧可能。承認制・非公開は、個人なら所有者だけ、共有ならOwnerとMember全員が送信直後の未回答質問を閲覧可能と説明する。個別公開で質問が、回答で質問と回答が公開されることと、投稿者アカウント情報を保存しない説明を維持する。

画面表示後の設定変更は送信時に再確認する。フォームが表示しているモードをServer ActionからConvexへ渡し、`questions.submit`の同一トランザクション内で現在値と比較する。不一致なら質問・レート制限行を変更せず現在モードを返す。フォームは説明を更新して入力を保持し、まだ送信していないことを通知する。自動再送せず、利用者が改めて送信する。再変更があれば再び止める。

DBスキーマは変更しない。既存APIクライアントとの互換性のためmutationの比較引数はoptional。今回のフォームは必ず指定する。旧クライアントの省略時は従来の投稿仕様を維持する。
